# 4hp Line Level Input

!()[https://github.com/Fihdi/LIN/blob/main/LIN-Front.png?raw=true]

The LIN (Line In) module converts any device with a headphone output (Groovebox, Radio, Laptop, Mp3-Player, etc) to Eurorack level. LIN features a high gain stereo VCA, the VCA can be used to create percussions, cutting up external audio signals or distorting existing Eurorack signals.

# VOL and CV knob

The **VOL** knob controls the base output level of the module. Modulating the output volume is possible by applying an external CV signal to the **CV** jack. The **CV** knob attenuates the incoming CV signal level.

# R and L outputs

The output jacks labeled **R** and **L** provide separate Eurorack level outputs for the right and left channels.
